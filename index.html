Settings

Created in Google Cloud Console. Add http://localhost:3000 to Authorized JavaScript origins.

Quick Setup Steps:

  1. Go to Google Cloud Console.
  2. Create a project & enable Google Calendar API.
  3. Under OAuth consent screen:
    • Add your email under Test users.
    • Under Scopes, add .../auth/calendar.readonly.
  4. Create Credentials → OAuth client ID → Web application.
  5. Set Authorized JavaScript origins to http://localhost:3000.
  6. Save your Client ID here, then sign in and check the "See and download events" box.
